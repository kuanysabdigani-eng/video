🚀 Как опубликовать сайт на GitHub и Vercel

  1. Сохрани этот код в файл с именем index.html.
  2. Создай новый репозиторий на GitHub и загрузи туда этот файл.
  3. Зайди на Vercel и нажми **Add New → Project**.
  4. Импортируй свой репозиторий и нажми **Deploy**. Никаких настроек сборки не нужно!
